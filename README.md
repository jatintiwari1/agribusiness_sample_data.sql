Agribusiness Data Model & SQL Performance Analysis

Project Overview

This project simulates a real-world agribusiness data analytics scenario using a relational database and SQL. The analysis focuses on production efficiency, yield trends, operational costs, sales revenue, profitability, weather-related patterns, and expense management.

The dataset used in this project is synthetic and created for academic/project demonstration purposes because no real-world dataset was provided.

Business Scenario

An agribusiness organization manages multiple farms, fields, crops, planting cycles, harvesting activities, employees, labour, equipment, suppliers, input purchases, markets, sales, crop prices, weather observations, and expenses.

The objective is to transform this operational data into useful KPIs and business insights that can support production planning, cost control, resource allocation, and revenue analysis.
